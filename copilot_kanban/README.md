# Kanban MVP

A simple, elegant Kanban board web app (Next.js, Tailwind CSS).

## Getting Started

1. `cd frontend`
2. `npm install`
3. `npm run dev`

## Testing

- Unit tests: `npm test`
- E2E tests: `npx playwright test`

## Features
- 1 board, 5 columns (renameable)
- Add, delete, drag cards
- No persistence, no user management

## Tech
- Next.js (TypeScript)
- Tailwind CSS
- @hello-pangea/dnd
- Jest, Playwright
